# AI Mapping

Release: 1.0.57  
Numeric version: 2026110602

## Summary
AI Mapping helps teachers connect learning outcomes with course activities and assessment evidence.

## Description
Teachers can review how course activities introduce, practise or assess each learning outcome. When AI Course Builder generates a mapping, the module receives only the outcomes pasted for that course unit, the actual activity content, and the links in the approved lesson plan.

## Features
- Map outcomes to activities and assessment evidence.
- Show introduced, practised and assessed coverage for each outcome.
- Preserve planned outcome-to-activity links in the generated matrix.
- Keep each AI Course Builder course scoped to its own unit outcomes.

## Requirements
- Moodle 4.0 or later, with the `mod_learningmapping` activity installed.

## Installation
- Install the exact `mod_learningmapping` release ZIP through Moodle's plugin installation page.
